# فایلو (Fileo)

[![Android CI](https://github.com/sajjadele/fileo/actions/workflows/android.yml/badge.svg)](https://github.com/sajjadele/fileo/actions/workflows/android.yml)

انتقال فایل سریع، امن و **بدون تبلیغ** بین دستگاه‌های اندروید — بدون سرور، بدون اکانت، بدون مزاحمت.

## چرا فایلو؟

اپ‌های رایج انتقال فایل (SHAREit، Zapya و…) شلوغ و پرتبلیغ‌اند و حریم خصوصی را نادیده می‌گیرند. فایلو با یک هدف ساخته می‌شود: **فقط انتقال فایل، به بهترین شکل.**

| اصل | یعنی |
|---|---|
| 🚀 سبک و سریع | اپ نیتیو Kotlin، APK کوچک، انتقال با سرعت واقعی Wi-Fi |
| 🔋 بک‌گراند صفر | سرویس انتقال فقط حین انتقال روشن است؛ در حالت عادی هیچ پردازشی در پس‌زمینه نیست |
| 🔒 قفل شبکه | اپ فقط به دستگاه‌های شبکه محلی وصل می‌شود؛ بدون سرور، بدون آنالیتیکس |
| 🎨 فارسی اول | طراحی RTL درجه‌یک، رابط فارسی روان، Material 3 |
| 🚫 بدون تبلیغ | هیچ‌وقت، هیچ‌جا |

## بیلد

بیلد کامل روی **GitHub Actions** انجام می‌شود (مناسب شبکه‌های ایران): هر push به `main` → اجرای تست‌ها + ساخت APK → دانلود از بخش [Actions](https://github.com/sajjadele/fileo/actions) در همان run.

```bash
# بیلد لوکال (اگر Android Studio و SDK دارید)
./gradlew assembleDebug
```
